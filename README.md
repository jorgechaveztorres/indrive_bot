# Asistente de Rentabilidad - Trujillo

Calculadora manual para evaluar carreras de inDrive / moto.

Uso:
  python main.py # evalúa una carrera
  python resumen.py # resumen del día

Costo real: S/ 0.18/km (moto)

No automatiza clics, solo recomienda ACEPTAR / NEGOCIAR / RECHAZAR según:
- schedules.json (franjas horarias)
- zones_trujillo.json (zonas complejas)
